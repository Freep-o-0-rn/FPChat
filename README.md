# FPChat MVP

Локальный MVP приватного текстового чата с инвайт-ссылками и клиентским шифрованием (E2EE-подход для MVP): сервер хранит только зашифрованные сообщения.

## Установка

```bash
npm install
cp .env.example .env
```

## Запуск

```bash
npm start
```

Приложение слушает только `127.0.0.1:3010`.

## Обновление на Windows

Запускайте `update.bat` с флешки из папки проекта. Апдейтер определяет папку по расположению самого файла, поэтому буква флешки может быть не `D:`. Ожидаемая структура: `<буква>:\FPChat\package.json`.

Апдейтер:

- проверяет исходную копию и Node.js 22.x;
- сначала собирает временную копию и выполняет `npm ci`, не меняя рабочую установку;
- останавливает сервер, запущенный через `start_chat.bat`, перед копированием и резервированием SQLite;
- сохраняет `data`, `.env` и предыдущую версию приложения в `C:\_BOTS\FPChat_backups`;
- не копирует с флешки `data`, `.env`, `node_modules` и `.git`;
- перезапускает сервер только если он работал до обновления.

Если порт FPChat занят процессом, который не удалось безопасно остановить, обновление прерывается. В этом случае остановите сервер вручную и запустите `update.bat` повторно.

## Проверка порта 3010

```bash
ss -ltnp | rg 3010
```

## Открытие локально

- Основной экран: `http://127.0.0.1:3010/`
- Invite URL: `http://127.0.0.1:3010/i/<ROOM_PUBLIC_ID>#<SECRET>`

## Что хранит сервер

SQLite хранит:
- комнаты;
- участников;
- зашифрованные сообщения (`ciphertext`, `iv`);
- статусы `sent / delivered / read` и timestamps;
- verifier для recovery (salt + hash), без открытого recovery кода.

Сервер **не хранит в открытом виде** ключи комнаты/пользователя/recovery и текст сообщений.
